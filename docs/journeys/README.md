# How Elicta is used

Twelve journeys, written from the point of view of the person doing the work.
Each one covers a moment in a real engagement, shows the actual screens, and
ends by saying plainly what is ready and what is not.

They are as much a status report as an introduction. A journey that describes
something we have not built yet says so in its own words — because a document
that quietly describes intentions reads exactly like one describing behaviour,
and there is no way for a reader to tell them apart.

## About the screenshots

Every image is captured from the running product, not drawn. They are taken
from fixed example data — one invented client, Northwind Logistics, appearing
across all twelve — so the same open question can be followed from the
preparation screen, through the meeting, into the write-up, and on to the next
meeting. Nothing in them is a real client, a real recording or a real
credential.

The screens are checked automatically against the WCAG 2.2 AA accessibility
standard, in light and dark appearance and at two window sizes, and that check
blocks a release if it fails.
